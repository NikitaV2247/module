# Модуль генерации упрощённого расписания занятий

Учебная практика по МДК 02.02 «Инструментальные средства разработки программных
модулей», Костромской политехнический колледж (КПК).

Модуль читает **учебный план** (3 группы, 8 дисциплин, часы и кабинеты),
**генерирует недельное расписание** с учётом звонков и занятости кабинетов,
строит человекочитаемые выборки (день / неделя / поиск), проверяет конфликты
и выгружает результат в консоль, TXT, CSV, HTML, iCal (.ics) и PDF.

## Возможности

- **период семестра 2 сентября – 20 декабря 2026 г.** (16 недель): расписание
  можно собрать на **любую неделю** — по номеру (`--week 1` — 1-я неделя
  сентября, `--week 13` — 4-я неделя ноября) или по дате (`--week 2026-11-23`),
  а также на **один день** (`--day 2026-10-08`);
- **генерация недели из учебного плана**: часы дисциплин делятся на недели
  семестра (1 пара = 2 ак. часа), пары расставляются по сетке звонков;
- **сетка звонков по дням недели** (zvonki.pdf, секция `bell_schedule`
  в data/curriculum.json): пн — 6 пар, вт–пт — 7, сб — 4; слот
  «Разговоры о важном» (пн 12:00–12:30) парой не является и в расписании
  не фигурирует;
- **автогенерация недели из учебного плана с записью в schedule.json**:
  пункт 7 меню собирает неделю **всех групп**, `--auto-schedule` — неделю
  одной группы; предметы и нагрузка берутся из curriculum.json, расстановка
  зависит от номера недели семестра — у каждой недели своё расписание,
  подпись недели и даты в schedule.json обновляются (бывший пункт 8 меню
  удалён и объединён с пунктом 7);
- **ограничения задания**: у группы — максимум **4 пары в день**, но по времени пары могут стоять вплоть до последней пары дня;
- **без «окон»**: пары группы в учебном дне идут подряд — промежутки не допускаются ни генератором, ни валидатором;
- **дни с 3–4 парами**: 13 пар недели концентрируются как 4 + 3 + 3 + 3;
- **кабинеты с альтернативами**: если кабинет занят другой группой, дисциплина уходит в следующий по списку (МДК 01.02: 408 → 412 → 405 → 406);
- **один предмет** — не более одного раза в день у группы;
- расписание любой группы на день и на **всю неделю с переменами**;
- в карточках выводятся **только занятия** — пустые пары не показываются;
- поиск по дисциплине — и по краткой форме («МДК 02.02»), и по полному названию;
- **проверка конфликтов** (группа / аудитория / преподаватель) и ограничений (сетка звонков своего дня — пн 6, вт–пт 7, сб 4; не больше 4 пар в день;
- **экспорт**: TXT, CSV, HTML (день и неделя), **iCal (.ics)**, **PDF (A4)**;
- **преподаватели**: у дисциплины один преподаватель — поле `teacher` в data/curriculum.json; он попадает в расписание (data/schedule.json), автогенерацию и все выгрузки; список преподавателей у занятия недопустим (валидация сообщает об ошибке);

Сетка звонков — по дням недели (секция `bell_schedule` в data/curriculum.json). «Разговоры о важном»
(пн 12:00–12:30) — не пара, поэтому в сетке и в расписании модуля

детерминированный режим); пункт 7 меню и `--auto-schedule` распределяют
те же пары по дням по-своему на каждую неделю семестра (расстановка
привязана к номеру недели).

«Разговоры о важном», в расписании модуля он не показывается), в субботу —
по 10 минут. Время пары в карточках и экспортах подставляется по сетке
именно того дня, на который занятие приходится.

## Как запустить и проверить всё

### 1. Генерация расписания из учебного плана

```bash
python -m src.main --generate                 # неделя с сегодняшней датой
python -m src.main --generate --week 1        # 1-я неделя сентября (2–5.09)
python -m src.main --generate --week 13       # 4-я неделя ноября (23–28.11)
python -m src.main --generate --week 2026-11-23   # та же неделя по дате
python -m src.main --generate --day 2026-10-08    # один день (четверг)
# 3 группы × 13 пар → data/schedule.json
```

### 2. Основные запросы

```bash
python -m src.main                                    # интерактивное меню
python -m src.main --group 4-1П9 --day Понедельник    # карточка дня
python -m src.main --group 4-1П9 --day 2026-11-10     # день можно и по дате
python -m src.main --group 4-1П9 --week               # неделя с переменами
python -m src.main --group 4-1П9 --auto-schedule      # автогенерация недели группы → schedule.json
python -m src.main --group 4-1П9 --auto-schedule --week 5   # на 5-ю неделю семестра
python -m src.main --conflicts                        # конфликты и ограничения
python -m src.main --search "МДК 02.02"               # поиск по дисциплине
```

### 3. Экспорт

```bash
python -m src.main --group 4-1П9 --week \
    --export-html week.html --export-ical week.ics --export-pdf week.pdf
python -m src.main --group 4-1П9 --day Понедельник --export-csv exports/day.csv
```

### 4. Тесты и покрытие

```bash
python -m pytest -q                                   # 150 тестов
python -m pytest --cov=src --cov-report=term-missing  # с покрытием
```

### 5. Линтеры (то же, что в CI)

```bash
black --check src tests && isort --check-only src tests && flake8 src tests
```

### 6. Что должно получиться

- `--generate --week 1`: 39 занятий (3 группы × 13 пар) только в учебные дни
  недели — среда … суббота; `--generate --week 13` — неделя 23–28 ноября;
  `--generate --day 2026-10-08` — расписание одного четверга;
- `--auto-schedule --week 5` и `--auto-schedule --week 6` дают группе разные
  расстановки (seed — номер недели), обе сохраняются в data/schedule.json:
  занятия группы заменены, подпись недели и даты обновлены,
  остальные группы — как были; повторный запуск той же недели даёт
  то же расписание;
- пункт 7 меню — то же, но для **всех групп** сразу: 39 занятий
  (3 группы × 13 пар) записываются в schedule.json целиком, расстановка
  привязана к номеру недели; пункта 8 в меню больше нет — он объединён
  с пунктом 7;
- у каждой группы дни с 3–4 парами (пн 4 + вт 3 + ср 3 + чт 3),
  пятница и суббота свободны; пары группы в дне идут подряд, без «окон»,
  и не выходят за сетку своего дня (в субботу — максимум 4-я пара);
- в карточке дня — только занятия группы с временем по звонкам своего дня
  (день с четырьмя парами — четыре строки, пустые пары не выводятся);
- в неделе — перемены между соседними парами (20/35/10 мин),
  дни без занятий — одна строка «занятий нет»;
- `--conflicts`: 0 конфликтов аудиторий (генератор их не допускает),
  0 конфликтов групп, нарушений сетки и лимита пар нет; конфликты
  преподавателя в сгенерированной неделе возможны (генератор пока
  не следит за занятостью преподавателя — ограничение эксперимента
  v0.7.2), в демо-данных их 5;
- одна и та же дисциплина в разных группах — в разных кабинетах,
  если основной занят (например, МДК 01.02: 408 / 412 / 405);
- несуществующая группа → «Ошибка: группа не найдена», код выхода 1;
- дата вне периода 02.09–20.12.2026 или воскресенье → понятная ошибка;
- `.ics` открывается в Google Calendar / Outlook;
- PDF — альбомный A4, кириллица без квадратиков;
- пункт 5 меню — экспорт недели группы в настоящий PDF-файл: Enter сохраняет exports/week_<группа>.pdf, имя без расширения дополняется «.pdf», каталог создаётся сам, печатается полный путь и размер файла.

Полный чек-лист: docs/qa_checklist.md.

## Архитектура

```
data/curriculum.json ─► loader (CurriculumLoader)
                        │  период семестра 02.09–20.12.2026 · 16 недель
                        ▼
                     semester (недели и дни периода)
                        │
                        ▼
                     scheduler (жадный + backtracking, кабинеты-альтернативы)
                        │  часы → пары/неделю · дни по 3–4 пары
                        │  сетка звонков своего дня (пн 6 · вт–пт 7 · сб 4)
                        │  пары дня — подряд, без «окон»
                        ▼
                 data/schedule.json ─► loader (DataLoader)
                                        │
                                        ├─► generator  (день/неделя/поиск)
                                        ├─► conflicts  (группа/аудитория/
                                        │               ограничения)
                                        └─► экспорт: exporter (TXT/CSV)
                                            · html_export · ical_export
                                            · pdf_export (reportlab)
```

- `models.py` — источник истины: сетка звонков по дням недели
  (пн — 6, вт–пт — 7, сб — 4 пары; из curriculum.json), лимит 4 пары
  в день, учебный план с периодом семестра;
- `semester.py` — недели семестра 1–16, выбор недели по номеру/дате
  и отдельного дня;
- `abbreviations.py` — краткие имена дисциплин для отображения;
- `main.py` — CLI (argparse) и интерактивное меню;
- диаграммы: docs/uml (ER, Use Case, Sequence, Классы, Activity).
