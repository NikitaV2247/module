# Нефункциональные требования и стек технологий

Согласовано командой на этапе проектирования (спринт 1, Этап 1).

## Производительность

| Требование | Значение | Проверка |
|---|---|---|
| Загрузка data/schedule.json (3 группы, 39 занятий) и учебного плана | < 1 с | `pytest tests/test_loader.py` |
| Выборка недели группы с переменами | < 1 с | `pytest tests/test_week_breaks.py` |
| Недели семестра 1–16 и выбор дня по дате | < 0,1 с | `pytest tests/test_semester.py` |
| Генерация недели всего колледжа (39 пар, backtracking) | < 5 с; бюджет перебора 100 000 шагов | `pytest tests/test_scheduler.py` |
| Поиск по дисциплине по всему колледжу | < 1 с | `pytest tests/test_generator.py` |
| Экспорт PDF (reportlab) | < 3 с | `pytest tests/test_pdf.py` |

## Надёжность и качество

- 150 unit-тестов, покрытие кода — 91% (бизнес-логика 89–100%, CLI —
  unit-тесты test_main + ручные сценарии QA — см. qa_checklist.md);
- CI на трёх версиях Python (3.10 / 3.11 / 3.12): линтеры + тесты + дымовой запуск;
- все внешние данные валидируются (структура JSON, сетка звонков, даты недели);
- ошибки пользователя возвращают понятные сообщения на русском, код выхода 1.

## Безопасность

- модуль работает локально, сетевых запросов нет;
- HTML-экспорт экранирует спецсимволы (`html.escape`), iCal — по RFC 5545;
- входные данные (номера пар, дни) проверяются по белым спискам (`choices`,
  `WEEKDAYS`, `BELL_SCHEDULE`).

## Поддерживаемость

- стиль кода: black + isort (profile=black) + flake8; enforced pre-commit'ом;
- docstrings на русском на все публичные функции и классы;
- структура src/tests/docs, имена по шаблону `feature/ISSUE-ID-short-name`.

## Ограничения (приняты командой)

1. Преподаватели добавлены экспериментально (v0.7.2): один преподаватель
   на дисциплину и занятие, ФИО вымышленные. Проверка teacher-конфликтов
   наполняется (в демо-данных 5) и включена в CI-конвейер (v0.7.3);
   генератор при пересборке недели занятость преподавателя пока
   не отслеживает.
2. Вместимость и оборудование аудиторий не моделируются (нет данных).
3. Учебная неделя шестидневная; iCal-экспорт требует календарных дат
   в data/schedule.json.
4. Пересборка `--auto-schedule` выполняется по одной группе и не
   учитывает занятия других групп (для полной координации — команда
   `--generate`, она собирает все группы сразу с выбором кабинетов).

## Стек технологий (согласовано)

| Слой | Выбор | Обоснование |
|---|---|---|
| Язык | Python 3.10+ | изучается в МДК 02.02; stdlib достаточно для логики |
| PDF | reportlab 4.x | единственная зрелая чистая библиотека PDF с кириллицей через TTF |
| Тесты | pytest + pytest-cov | стандарт де-факто, отчёты для CI |
| Стиль | black, isort, flake8 | автосогласованный стиль, минимум споров на ревью |
| Хуки | pre-commit | проверки до коммита, а не после пуша |
| CI | GitHub Actions | бесплатный для учебных репозиториев, матрицы версий |
| Шрифты | DejaVu Sans (MIT-подобная лицензия) | кириллица «из коробки», поставляется в assets/fonts |
