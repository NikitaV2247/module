# Анализ предметной области

## 1. Описание предметной области

Костромской политехнический колледж (КПК) — среднее профессиональное
учебное заведение, в котором обучается несколько десятков учебных групп
по направлениям: архитектура (А), бухгалтерский учёт (Б), строительство
(С), программирование и прикладная информатика (П), радиоэлектроника (Р),
механика (М), ТЭС и другие.

Расписание занятий в колледже имеет следующие особенности:

- учебная неделя длится с понедельника по субботу (6 дней);
- занятия проводятся парами; в исходных файлах — до 7 пар в день;
  с v0.7.0 время пар берётся из сеток звонков учебного плана по дням
  недели (пн — 6 пар, вт–пт — 7, сб — 4), при этом у группы — не более
  **4 пар в день** (по заданию);
- каждая пара имеет номер (1–7), предмет и кабинет;
- предмет может делиться по подгруппам: запись
  «Стр.черчение/рисунок» означает, что 1-я подгруппа занимается
  черчением, 2-я — рисунком (кабиненты в этом случае указываются
  через дробь: «220/226»);
- предметы записаны сокращениями («Ин.язык», «Осн.бух.учета»,
  «МДК 02.02»), часть помечена как «ср» (самостоятельная работа)
  или «ПРАКТИКА» (производственная практика);
- группы имеют коды вида «2-1П9»: курс − номер группы − литера
  направления − класс поступления (9 или 11 класс).

Исходные данные практики — файлы «ИЗМЕНЕНИЯ В РАСПИСАНИИ ЗАНЯТИЙ»
за неделю 5–10 октября (6 файлов, понедельник — суббота), всего
35 учебных групп и 711 записей о занятиях. С версии 0.3.0 модуль
работает от учебного плана: data/curriculum.json описывает 3 группы,
8 дисциплин (428 часов) со списками кабинетов и вымышленными ФИО
преподавателей (v0.7.2); неделя расписания (data/schedule.json)
собирается из плана на любую из 16 недель семестра (02.09–20.12.2026) —
в демо-данных это 3-я неделя (14–19 сентября), 39 занятий.

## 2. Проблемы, которые решает модуль

| Проблема | Решение в модуле |
|----------|------------------|
| Расписание хранится в громоздких таблицах Word | Данные переводятся в структурированный JSON |
| Сокращения предметов непонятны | Словарь расшифровок (более 100 записей) |
| Неудобно искать «свои» пары среди всех групп | Выборки по группе, дню, предмету |
| Нет времени начала пар | Типовые времена пар добавляются автоматически |
| Расписание неудобно распечатать/отправить | Экспорт в TXT, CSV, HTML, iCal и PDF (неделя группы — одним PDF-листом A4) |

## 3. Пользователи модуля

- **Студент** — просматривает расписание своей группы на день или неделю,
  ищет, в каком кабинете проходит нужный предмет.
- **Преподаватель/заведующий учебной частью** — просматривает сводную
  доску дня по всем группам, проверяет загрузку кабинетов.
- **Команда разработки** — использует JSON-данные и программный интерфейс
  модуля в других проектах колледжа.

## 4. Границы системы (упрощения)

Модуль сознательно **упрощён** в рамках учебного задания:

- автоматическое построение ограничено неделей: пересборка недели группы
  (`--auto-schedule`, v0.5.0) и сборка недели колледжа из учебного плана
  (`--generate`); расписание семестра целиком с нуля не строится;
- преподаватели добавлены экспериментально (v0.7.2): один преподаватель
  на дисциплину и занятие, ФИО вымышленные; занятость преподавателя при
  пересборке не отслеживается — в демо-данных 5 teacher-конфликтов;
- время пар задаётся сетками звонков своего дня из учебного плана
  (пн — 6 пар, вт–пт — 7, сб — 4);
- расписание охватывает одну неделю семестра (пересобирается на любую
  из 16 недель).

## 5. Входные и выходные данные

**Вход:** `data/curriculum.json` — учебный план (3 группы, 8 дисциплин,
сетки звонков по дням, преподаватели); `data/schedule.json` — собранная
неделя расписания (3 группы, 39 занятий).

**Выход:**
- текстовые карточки расписания (консоль, TXT);
- таблица CSV (День; Группа; Пара; Время; Предмет; Кабинет; Преподаватель);
- HTML-страница с оформленной таблицей расписания;
- неделя группы в iCal (.ics) и в PDF (A4, ландшафт).
